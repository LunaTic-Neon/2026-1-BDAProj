5주차 영화 대시보드와 똑같은 멀티페이지 구조입니다. 새로운 기술은 없습니다.
빈칸(TODO)을 내 데이터에 맞게 채우기만 하면 앱이 완성됩니다.

복사로 시작

폴더를 통째로 복사해 내 프로젝트로 만듭니다. 처음부터 만들 필요가 없습니다.

한 줄만 연결

데이터 읽는 곳은 단 한 곳. load_data() 한 줄만 내 데이터로 바꿉니다.

경로 택1

ML·이미지·텍스트·LLM 중 내 데이터에 맞는 길 하나만 골라 완성합니다.

2. 시작하기 — 3단계

1
폴더 복사project_template 폴더를 복사해 내 프로젝트 폴더로 (예: my_project)
2
의존성 설치 pip install -r requirements.txt
3
실행 streamlit run app.py샘플 데이터로 곧바로 동작합니다 → 잘 도는지 먼저 확인!
먼저 샘플 데이터로 실행이 되는지 확인한 뒤, 내 데이터로 교체하세요. "동작부터 시키고 → 그다음 꾸미기"가 핵심 전략입니다.

3. 전체 폴더 구조

project_template/ ├── app.py # 진입점 (st.navigation) — 제목/이름만 수정 ├── requirements.txt # 의존성 (쓰는 것만 남기고 삭제 가능) ├── README.md # 작업 순서 안내 ├── 보고서_템플릿.md # 제출용 보고서 양식 │ ├── pages/ # 화면 (작업 순서 = 1 → 2 → 3) │ ├── 1_EDA.py # 1차: 개요·요약·결측·발견 │ ├── 2_시각화.py # 2차: 그래프 + 해석 │ └── 3_모델_서비스.py # 3차: 입력→예측→결과 ★핵심 │ ├── src/ # 로직 │ ├── data_loader.py # load_data() — 데이터 연결 (한 줄만 수정) │ └── features.py # clean() / add_features() — 정제·특성 │ ├── data/ # 데이터 파일 │ ├── sample.csv # 동작 확인용 예시 (합격 예측 320행) │ └── images/cat,dog/ # 이미지 샘플 (클래스 = 폴더 이름) │ └── 이미지_데이터_쓸_때/ # 이미지 프로젝트용 변형본 (2파일 교체)

4. 핵심 원리 — 데이터 입구는 한 곳

모든 페이지가 load_data() 하나만 가져다 씁니다. 그래서 이 한 줄만 내 데이터로 바꾸면 EDA·시각화 화면이 그대로 동작합니다.

# src/data_loader.py import pandas as pd import streamlit as st @st.cache_data # ★ 데이터는 한 번만 읽고 캐시에 보관 (속도↑) def load_data(): df = pd.read_csv("data/sample.csv") # 👈 TODO: 내 파일 경로로 변경! return df # CSV 한글 깨지면: encoding="utf-8" 또는 "cp949" # 너무 크면 개발 중엔: nrows=50000 로 일부만

5. 화면 = 작업 순서

페이지 번호가 곧 작업 순서입니다. 앞에서부터 차례로 채워 나갑니다.

1_EDA

데이터 들여다보기
행·열 수, 요약통계, 결측치, 그리고 "내가 발견한 것" 메모.

2_시각화

그래프로 인사이트
plotly 분포·관계 그래프. 그래프마다 "그래서 무엇?" 한 줄 해석.

3_모델·서비스

입력→예측→결과
이 프로젝트의 핵심. 4가지 경로 중 하나를 골라 완성.

1·2번 페이지는 대부분 그대로 동작합니다. 컬럼 이름과 해석 문장만 내 데이터에 맞게 채우면 됩니다.

6. 모델·서비스 — 경로 A~D 택1

내 데이터 유형에 맞는 한 가지 경로만 남기고 나머지는 지웁니다. 모두 우리가 배운 내용입니다.

경로방법이럴 때배운 곳
Ascikit-learn (RandomForest)표(CSV) 분류·회귀10주
B사전학습 ViT pipeline이미지 분류11·12주
CHuggingFace pipeline텍스트 감정·요약5주
DOllama 로컬 LLMLLM 챗·생성 서비스6주
MVP 목표: 사용자 입력 → 모델/LLM 결과 → 화면 표시. 동작부터 시킨 뒤 꾸미세요. 기본 템플릿엔 경로 A만 켜져 있고 B·C·D는 주석 처리되어 있습니다.

7. 경로 A 예시 — 표 데이터 ML

@st.cache_resource # ★ 모델 학습/로드는 한 번만 def train_model(): df = load_data() target = "target" # 👈 TODO: 예측할 컬럼 이름 X = df.drop(columns=[target]).select_dtypes("number") X = X.fillna(X.median()) # RandomForest는 NaN 불가 y = df[target] Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.2) model = RandomForestClassifier(n_estimators=200) model.fit(Xtr, ytr) return model, list(X.columns), metrics # → 정확도·F1 표시 → number_input으로 입력 받아 예측 버튼

바꿀 곳은 사실상 target 컬럼 이름 하나입니다.

8. 이미지 데이터를 쓸 때

표가 아닌 이미지 폴더로 한다면, 적재·EDA 2개 파일만 교체하면 됩니다.

파일 2개 덮어쓰기

data_loader_image.py → src/data_loader.py
1_EDA_image.py → pages/1_EDA.py

클래스 = 폴더 이름

data/images/cat/, dog/ ...
샘플 이미지가 이미 들어 있어 바로 실행됩니다.

이미지를 전부 메모리에 올리지 않고 경로·라벨·크기 메타데이터만 스캔합니다(강의실 8GB 보호). 모델은 경로 B(ViT)를 켜세요. 2_시각화.py는 수정 불필요!
